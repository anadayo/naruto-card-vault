# NARUTO CARD VAULT

Unofficial information hub for the NARUTO CARD GAME scheduled for worldwide release in June 2027.

## Local preview

```sh
python3 -m http.server 3344
```

Open `http://localhost:3344/naruto-card-vault/` when serving from the parent workspace.

## Publishing

The site is intended for the standalone GitHub Pages repository `anadayo/naruto-card-vault`.

Official artwork is not bundled. The official website prohibits unauthorized reuse of its images and text, so this site uses an original generated hero visual and links to primary sources.
